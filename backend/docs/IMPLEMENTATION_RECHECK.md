## 多账号配置

涉及账户身份、验证码、设备实际值及群组的设置必须追加 `_手机号`，例如环境键 `CAIYUN_APP_NOTICE_STATUS_13800000001`。无对应账号配置时，任务只查询或跳过写入，不读取同名全局配置。

| 键前缀 | 内容 |
| --- | --- |
| `CAIYUN_APP_NOTICE_STATUS` | 该账号实际 APP 通知状态，严格为 `0` 或 `1` |
| `CAIYUN_ALBUM_BACKUP_STATUS` | 该账号实际相册备份状态，严格为 `0` 或 `1` |
| `CAIYUN_STUDENT_SMS_CODE` | 该账号已完成认证后收到的验证码 |
| `CAIYUN_PRIZE_OID`、`CAIYUN_PRIZE_SMS_CODE` | 同一账号、同一奖品的 OID 与已收到验证码；任务不会重新发送短信 |
| `CAIYUN_FAMILY_GROUP_ID` | 该账号家庭圈群组 |
| `CAIYUN_REDINVITE_CODE` | 此账号要接受的红包邀请码 |
| `CAIYUN_UNLOAD_CODE`、`CAIYUN_UNLOAD_TYPE` | 此账号的 1T 新礼兑换码与类型 |
| `CAIYUN_AISTORE_SAVE_MODULE` | 此账号明确要保存作品的模块号 |

短信发送和授权提交的 API 已封装，任务不自动求解滑块或替用户接受授权协议。短信验证码须先经官方流程取得，再按账号与奖品传入。

## 部署与验证

升级时须执行项目既有迁移命令，迁移器会把新增任务同步到 `task_configs`，并保留管理员的启停设置：

```powershell
cd backend
go run ./cmd/caiyun migrate
```

此命令会写数据库，本次核对未执行它。Docker 部署的账号环境键需显式传入 worker 的环境或 `env_file`；仅把变量写进根目录 `.env` 不会自动传入容器。

验证命令为后端 `go test ./...`、`go vet ./...`，前端 Vue 类型检查、ESLint、Vitest，以及 `git diff --check`。新增测试均替换 HTTP 传输器；不会以模拟成功证明真实奖励已入账。

2026-09-30 验证结果：后端全量测试、静态检查和构建通过；前端类型检查、ESLint、11 个测试文件的 44 项 Vitest 测试通过。需要实际 Redis 的集成测试按现有环境开关跳过，真实账号及奖励到账未验证。

## 仍受条件限制的功能

- 学生福利需要真实认证、资格和验证码；领奖专区需要官方滑块流程及逐奖品验证码。
- APP 通知、相册备份必须有该账号的实际设备状态；连续天数、跨月、运营商号码、库存和互助资格不能在代码中补造。
- 家庭圈基线宿主未被参考材料确认可用；1T 新礼、朋友圈九图保存及部分邮箱桥接在参考环境中不可达。相应任务具备探测/报告路径，不能称为线上全功能已完成。
- 趣玩 AI 邮箱版负责登记和抽奖；真实 AI 产出由云盘版动作负责，单次登记不等于完成活动。
- 真实账号的完成位与奖励到账还需测试环境运行确认；本次没有据此宣称 100% 线上可用。
