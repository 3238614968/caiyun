## 升级与启用

本轮没有新增数据库表或 SQL 迁移。部署新版后端后执行 `caiyun-linux migrate`（本地为 `go run ./cmd/caiyun migrate`）同步任务定义，再重启 API、Worker。同步会插入 `lantern`、`liveflower`，更新活动描述与批次标记，并保留已有 `is_enabled` 设置。2026-11-01 起 `cloudphone` 因登录迁移停用；`shake` 如需启用可在管理页面操作，新增两项默认启用并加入日常批次。活动结束或不适用于账号时可通过现有任务配置关闭。

抽抽乐默认次数为 3、间隔为 1500 毫秒，分别由 `CAIYUN_TASK_SHAKE_TIMES`、`CAIYUN_TASK_SHAKE_DELAY_MS` 控制；次数 0 表示跳过。Docker Compose Worker 与 Kubernetes ConfigMap 已提供这两个配置。
